# mission-control-ai-1CCPF
GS 1 - Pensamento Computacional e Automação com Python

O Mission Control AI é um sistema desenvolvido em Python capaz de simular o monitoramento inteligente de uma missão espacial.
O projeto:
Armazena dados de diversos ciclos de monitoramento.
-Analisa automaticamente indicadores críticos.
-Gera alertas quando situações de risco são detectadas.
-Calcula o nível de risco de cada ciclo.
-Identifica tendências de piora ou melhora da missão.
-Detecta qual área apresenta mais falhas.
-Produz um relatório final para auxiliar a tomada de decisão.
